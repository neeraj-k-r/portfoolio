## ✨ Features & Highlights

- **Wildcard Subdomain Routing (`*.portfoolio.me`)**: Edge-rendered via Cloudflare Workers with full server-side rendering (SSR), high-speed edge caching, and instant fallback routing.
- **Dual-Track Personalization**:
  - **Technical Track**: Built for developers, software engineers, and computer scientists. Highlights GitHub repositories, live demo links, technical skill badges, and proof-of-work evidence.
  - **Visual & Creative Track**: Built for designers, creative technologists, video editors, 3D artists, and photographers. Highlights media galleries, showreel backdrops, project case studies, and services.
- **39 Handcrafted Templates**: Complete responsive layouts with tailored typography, fluid micro-interactions, dark/light modes, and custom aesthetic treatments.
- **Interactive Theme Showcase & Modal Previewer**: Browse and preview every template inside live browser mockups right from the homepage gallery or inside the Studio editor.
- **Proof of Work (Skill Evidence)**: Automatically derives verifiable skill proficiency by linking repositories, live demo URLs, and project tech stacks with GitHub verification indicators.
- **ATS-Friendly Resume Builder**: Auto-compiles portfolio profile data into 4 printable resume themes (`ats`, `modern`, `midnight`, `terminal`) with direct Print / Save-as-PDF support and pasted-text import.
- **Custom Site Hosting (Bring Your Own Site)**: Upload a prebuilt `.zip` or `.html` bundle to host custom static sites on `username.portfoolio.me` via Supabase Storage.
- **Cloudinary Integration**: Fast, unsigned image hosting for high-resolution project cover images, photo collages, and profile avatars.
- **Instant Publishing & Studio Dashboard**: Real-time editor with instant autosave, theme switching, tab-based organization, and moderation controls.

## 🚀 Getting Started Locally

### Prerequisites
- Node.js (v18+ recommended)
- Python 3 (or any static HTTP file server)

### 1. Clone the repository
```bash
git clone https://github.com/neeraj-k-r/portfoolio.git
cd portfoolio
```

### 2. Run local development server
Using Python:
```bash
python -m http.server 8000
```
Or using Node `npx serve`:
```bash
npx serve .
```
Open [http://localhost:8000/frontend/](http://localhost:8000/frontend/) in your browser.

### 3. Run automated test suites
All tests run with Node's native test runner (zero external dependencies):
```bash
node --test frontend/templates.test.mjs frontend/theme-preview.test.mjs frontend/visual-themes.test.mjs
```

## 🌐 Wildcard Subdomain & Edge Deployment (Cloudflare Worker)

Portfoolio uses a Cloudflare Worker on `*.portfoolio.me/*` to serve wildcard subdomains without requiring expensive DNS alias tiers.

1. **DNS Setup**:
   - `A @` → `75.2.60.5` (Netlify apex, DNS-only / grey cloud)
   - `CNAME www` → `<your-site>.netlify.app` (DNS-only)
   - `CNAME *` → `portfoolio.me` (Cloudflare Proxied / orange cloud — routes to the Worker)
2. **Deploy Worker**:
   ```bash
   cd backend
   npx wrangler login
   npx wrangler deploy
   ```
3. **SSL/TLS**: Set Cloudflare SSL to **Full** (Netlify serves the apex with Let's Encrypt; Cloudflare edge cert covers `*.portfoolio.me`).

## 🗄️ Database & Storage Configuration (Supabase)

1. Create a Supabase project at [supabase.com](https://supabase.com).
2. Copy your **Project URL** and **Anon Public Key** into `backend/supabase-config.js`.
3. Open Supabase **SQL Editor** and execute `backend/supabase-schema.sql`:
   - Configures `profiles` table with JSONB support for works, projects, and resume data.
   - Sets up open-publishing Row Level Security (RLS) policies.
   - Creates the `portfolio-sites` public storage bucket for custom ZIP uploads.
4. In Supabase **Authentication** → **Providers** → **Email**:
   - Turn **Confirm email OFF** for instant friction-free publishing.

## 📸 Media Uploads (Cloudinary)

1. Create a free account at [cloudinary.com](https://cloudinary.com).
2. Settings → **Upload** → **Upload presets** → Add new unsigned preset.
3. Add your cloud name and preset to `frontend/cloudinary-config.js`.
